# PortfolioOS

My very own portfolioOS!
I really wanted to make this for a while now since I haven't had the time to create my own professional portfolio.

My aim with this is to:

- Create an interactive portfolio OS that showcases my experience, skills, and projects.
- Learn software engineering processes and best practices, including software testing, CI/CD, containerisation, and deployment. Mainly to learn new skills that I'm missing out on in my current role.
- Document decisions and things that I learn along the way. I don't want to just do the technical stuff when working on this project, so I will also be including some documentation related to software engineering practices, like the following:
  - Product requirements
  - User stories
  - Wireframes & mockups
  - Architecture diagrams
  - Architecture decisions
  - Testing strategies
  - CI/CD pipeline diagrams
  - Learning log
